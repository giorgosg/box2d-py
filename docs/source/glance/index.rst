Modules at a Glance
===================

These pages list what each part of box2d-python offers, one line per member,
grouped by what it is for. The pages on the world, bodies, shapes and joints
cover every public method and property, with its parameters as the code takes
them, and each ends with a short example. The :doc:`../api/api` documents
every one in full, and the guides, starting with :doc:`../guides/concepts`,
explain how they fit together.
