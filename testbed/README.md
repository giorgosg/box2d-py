# box2d-testbed

The interactive testbed for [box2d-python](https://pypi.org/project/box2d-python/):
scenarios to run and step through, a scene editor, and debug drawing.

```bash
pip install --pre box2d-testbed
box2d-testbed
```

It is a separate package so that a game, or a page in the browser, does not
pay for it. `pip install "box2d-python[testbed]"` installs it too.

See [the testbed's documentation](https://box2d-py.readthedocs.io/en/latest/testbed/running.html).
